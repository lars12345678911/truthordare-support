# Truth or Dare · Support and privacy

Static support and privacy information for the Truth or Dare iPhone and iPad app, in English and Norwegian Bokmål.

Site address: https://lars12345678911.github.io/truthordare-support/

| Language | Home | Support | Privacy |
|---|---|---|---|
| English | `index.html` | `support.html` | `privacy.html` |
| Norsk bokmål | `nb/index.html` | `nb/support.html` | `nb/privacy.html` |

All paths are relative to the site address. GitHub Pages serves the `main` branch root. The `.nojekyll` marker allows these static files to be served directly.

No build step or JavaScript is required. The website uses a local stylesheet and system fonts, with no analytics, advertising, contact form or external font dependency. This repository contains no iOS app source, signing materials or game-session data.

Publisher and support contact: Lars Ask, lars.ask@outlook.com.
